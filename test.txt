==========================================================
DOCUMENTATION API COMPLÈTE - SYSTÈME D'EXAMENS (v1.0)
==========================================================

1. AUTHENTIFICATION ET COMPTES (Auth - CRUD)
---------------------------------------------
- Inscription (Create) :
  POST http://localhost:3000/api/auth/register
  Body JSON : {"email":"michel@supnum.mr","password":"123","role":"etudiant","matricule":"24133","nom":"Michel"}

- Connexion :
  POST http://localhost:3000/api/auth/login
  Body JSON : {"email":"michel@supnum.mr","password":"123"}

- Modifier un profil (Update) :
  PUT http://localhost:3000/api/auth/users/:id
  Headers : Authorization: Bearer <TOKEN>
  Body JSON : {"nom":"Michel Nouveau", "password":"nouveau_password"}

- Supprimer un compte (Delete) :
  DELETE http://localhost:3000/api/auth/delete/:id
  Headers : Authorization: Bearer <TOKEN>


2. GESTION DES EXAMENS (Exams - CRUD COMPLET)
----------------------------------------------
- Ajouter un examen (Create) :
  POST http://localhost:3000/api/exams/create
  Headers : Authorization: Bearer <TOKEN>
  Body : {"title":"Examen IA", "file_path":"sujet_ia_2025.pdf"}

- Voir tous les examens (Read) :
  GET http://localhost:3000/api/exams
  Headers : Authorization: Bearer <TOKEN>

- Télécharger un sujet d'examen :
  GET http://localhost:3000/api/exams/download/sujet_ia_2025.pdf
  Headers : Authorization: Bearer <TOKEN>

- Modifier un examen (Update) :
  PUT http://localhost:3000/api/exams/update/:id
  Headers : Authorization: Bearer <TOKEN>
  Body : {"title":"Examen IA Modifié"}

- Supprimer un examen (Delete) :
  DELETE http://localhost:3000/api/exams/delete/:id
  Headers : Authorization: Bearer <TOKEN>


3. GESTION DES TRAVAUX (Works - Soumission)
-------------------------------------------
- Soumettre/Uploader une réponse (Étudiant) :
  POST http://localhost:3000/api/works/submit
  Headers : Authorization: Bearer <TOKEN>
  Form-data : reponse=@michel_examen.txt

- Voir tous les travaux rendus (Enseignant uniquement) :
  GET http://localhost:3000/api/works/all
  Headers : Authorization: Bearer <TOKEN>

- Vérifier/Télécharger un rendu :
  GET http://localhost:3000/api/works/download/24133-michel_examen.txt
  Headers : Authorization: Bearer <TOKEN>


4. JOURNAUX (Logs)
------------------
- Consulter l'historique :
  GET http://localhost:3000/api/logs
  Headers : Authorization: Bearer <TOKEN>


==========================================================
DÉTAILS TECHNIQUES
==========================================================
- Format Nommage : {matricule}-{nom_original}
- Exemple : 24133-michel_examen.txt
- Sécurité : Bearer Token obligatoire pour toutes les actions CRUD
